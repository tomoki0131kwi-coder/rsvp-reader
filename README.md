# RSVP多読

RSVP（Rapid Serial Visual Presentation：単語を1語ずつ画面中央に高速表示する方式）で英語の多読をするための、Android向けWebアプリ（PWA）です。Chromeで開いて「ホーム画面に追加」すると、普通のアプリのように全画面・オフラインで使えます。

## 機能

- **今日のチェックリスト（ホーム画面）**: 毎日の学習（多読・単語学習・1文章トレーニング・多聴・週1回の確認テスト）を学習記録から自動で完了判定し、各項目のボタンからすぐ始められる。シャドーイングなどアプリ外の学習も項目として追加し手動でチェック可。全項目完了の連続日数（🔥）と直近7日の達成状況、「いつ・どこで学習するか」のメモ、毎日のリマインダーをGoogleカレンダー／.icsで登録
- **練習タブ（読む以外の学習）**:
  - 英文法コース: 関正生『真・英文法大全』（KADOKAWA）の章・節に沿って、1節ずつ 読む（本のページ）→ 要点 → 確認問題 → 実例（収録している本から、その文法が使われた英文を探す）→ 理解度の自己評価。確認問題は間違えたものほど早く「復習」に出題。章末テスト（目標8割）。全23章（291節・1,149問）
    - 要点と確認問題はこのアプリのオリジナルです（本の解説・例文は収録していません）。解説は本で読みます
    - 自分でスキャンした本を取り込むと、節のページをアプリ内で開けて、本全体を全文検索できます（下の「英文法の本の取り込み」）
  - シャドーイング（音声知覚）: VOA のネイティブ音声を約1分ずつの区間に分け、聞く → スクリプト確認（辞書・和訳）→ オーバーラッピング×5 → シャドーイング（音声認識で一致率と言えなかった語を表示、または録音して聞き比べ）。区間の開始位置は推定のため ±1秒で調整でき、話ごとに記憶
  - リピーティング（音声知覚）: 1文ずつ聞いて文字を見ずに繰り返し、その場で一致率を表示
  - 瞬間英作文（文章化）: Tatoeba の日英対訳4,000文（5レベル・文法タグ）。日本語を見て声かキーボードで英語に → 模範解答との差分・一致率 → お手本を聞いて音読・暗唱 → 自己評価（間隔反復で再出題）。10問ごとに「もう一度」の文を再チャレンジ
  - 1分間スピーチ（概念化・実践力）: 36のお題、「結論→理由→結論」の型とメモ、60秒の文字起こし、語数・速さ・型の言い回しの自動確認、5点満点の自己採点と改善点メモ（次回表示）
  - 音声認識は Android Chrome の Google 音声認識を使用（話した音声は Google に送信）。使えない端末では録音と自己評価で練習
- **RSVP表示**: 100〜1000 WPM。注視点（ORP）の1文字を色付けして中央に固定。句読点・文末・段落で自動的に少し止まる。1〜3語ずつの表示も可
- **スラッシュリーディング**: 表示単位を「まとまり」にすると、前置詞・接続詞・関係詞・動詞の前などで区切った意味のまとまりごとに表示（例: `Then old Mrs. Rabbit / took a basket / and her umbrella,`）。一時停止中の本文にも / を表示。読書画面の表示単位ボタンで 1語→2語→3語→まとまり を切り替え
- **本**: 6段階のレベル別に130冊を同梱（短い順）。Lv0は学習者向けの英語絵本（Global Storybooks、約700話を長さ別の短編集41冊に）、Lv2にVOA Learning Englishの「American Stories」（Poe・O. Henry・Twainなどを学習者向けに書き直した29話）、Lv1〜5にProject Gutenbergから厳選した60冊。さらに約6万2千冊の英語書籍をタイトル・著者で検索してダウンロード可能。手元の `.txt` も読み込み可
- **しおり**: 本ごとに読んだ位置を自動保存し、続きから再開
- **巻き戻し・文脈表示**: 一時停止すると前後の文章を表示。前の文／次の文、±10語、進捗バーで移動。再開時は文頭に戻る（設定で変更可）。目次から章へジャンプ
- **辞書**: 一時停止中に単語をタップすると意味を表示。英和（EJDict、同梱のためオフラインで使える）と英英（Free Dictionary API、オンライン時のみ）。活用形（went, running など）は原形も検索
- **発音**: 英和辞典と同じ形式の発音記号（例: run /rʌ́n/、water /wɔ́ːtər/）を約12万6千語ぶん同梱。🔊ボタンで端末の英語音声で読み上げ（設定で音声を選択可。英語音声が端末にない場合は追加方法を案内）
- **和訳**: 一時停止中の文章に日本語の機械翻訳を表示（「和訳」ボタンで切り替え）。現在の段落は自動、前後の段落はタップで翻訳。一度訳した段落は端末に保存され、再表示に通信は不要
- **レベル別語彙（自動調整）**: 一般英語の頻度で並べた約1万7千語を9レベル（Lv1＝上位1,000語 … Lv9＝13,001〜17,000位）に分けて学習。最初に4択の「レベル診断」で推定語彙数と開始レベルを決定。新しい単語の6割以上を最初から知っていれば（「簡単」）その場でレベルが上がり、復習の正答率が65%を下回ると下がる。知っていた単語は1か月後に確認し、今日の新出語の枠は消費しない
- **単語デッキ**: 「基本850語」「重要2000語」（EJDict の頻出語リスト）を、同梱の本での出現頻度順に1日5〜30語ずつ学習。例文は同梱のやさしい本から選んだもの
- **単語学習の目標と確認テスト**: 1日の学習回数の目標（既定50回）と進み具合を表示。復習で間違えたら音読3回の練習をはさむ（設定でオフ可）。学習した単語から20問の4択確認テスト（目標9割。間違えた単語は復習に戻る。7日ごとにテストを促す）
- **単語帳と復習**: 辞書で引いた単語を、原形・意味・発音・出てきた英文と一緒に自動保存（went → go のように原形でまとめる）。「単語」タブで間隔反復（SM-2方式）のフラッシュカード復習。最初は「英→日」、2回正解した後は英文の穴埋めで出題。忘れた単語は10分後にもう一度出題。同じ単語を読書中に引き直すと自動で復習に戻る。CSV書き出し可
- **聞き読みモード**: 読書画面の🎧ボタンで、英語音声で文ごとに読み上げながら、読み上げ中の単語をRSVP表示（リスニングと読解を同時に鍛える）。速さはWPM設定に連動（目安100〜300）。音声エンジンが単語位置を通知しない端末では、読み上げ速度から推定して文ごとに同期
- **多聴モード**: 🎧ボタンを押すたびに「オフ → 聞き読み → 多聴」と切り替え。多聴では文字を出さずに音声だけで聞き、一時停止中の本文はぼかし表示（「本文を表示して確かめる」で確認）。理解度はパーセントで記録し目標80%と比較。聞いた語数は多読とは別に「多聴」として記録
- **理解度チェック**: 章の区切り（300語以上読んだ後）や2,500語ごと、読了時に「よく分かった／だいたい／難しかった」を1タップで記録。直近の結果から「速さを上げる・下げる」「上・下のレベルの本へ」を提案し、ボタン1つで反映。記録画面に直近20回の集計
- **1文章トレーニング**: 読書中に一時停止して「📝 1文章トレーニング」を選ぶと、今の短い章（絵本の1話など）か、ここから100〜450語の文章で速読の練習。黙読（時間計測）→ 理解度 → チャンク確認（スラッシュ・辞書・和訳）→ 音声を5回聞く → 音読5回または20回（最後は速音読）→ もう一度黙読、の順に進め、練習前後のWPMを比較
- **目標管理**: 「1回目の黙読で150 WPM・理解度80%」（設定で変更可）を目標に、記録画面で達成状況・直近5回の平均・推移グラフ（理解度の達成は塗りつぶしの点）・一覧を表示。3回連続で達成すると目標を25 WPM上げる提案
- **読書記録**: 累計語数、今日の語数と目標、連続日数、平均速度、読書時間、2週間のグラフ、読了した本
- その他: ライト／ダークテーマ、文字サイズ・書体、読書中の画面スリープ防止、Androidの戻るボタン対応、バックアップの書き出し／読み込み

## パソコンで試す

Python 3 があれば、このフォルダで次を実行し、ブラウザで http://localhost:8765 を開きます。

```
python -m http.server 8765
```

開発中に古いファイルが表示されないよう、localhost ではオフライン機能（Service Worker）を無効にしています。試したいときは http://localhost:8765/?sw を開いてください。

## スマホで使う（公開する）

PWAとしてインストールするにはHTTPSで公開する必要があります。静的ファイルだけなので、無料のホスティングで動きます。

### GitHub Pages の場合

1. GitHubで新しいリポジトリを作る（例: `rsvp-reader`）
2. このフォルダの中身をアップロードする（`tools/.cache` は不要）
   ```
   git init
   git add .
   git commit -m "RSVP多読"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/rsvp-reader.git
   git push -u origin main
   ```
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存
4. 数分後、`https://<ユーザー名>.github.io/rsvp-reader/` で公開される

### Netlify Drop の場合

https://app.netlify.com/drop にこのフォルダをドラッグ＆ドロップするだけで公開できます（無料アカウントが必要）。

### Androidでインストール

1. Chromeで公開したURLを開く
2. メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面のアイコンから起動

## Gutenbergからのダウンロードについて

Project Gutenbergのサーバーはブラウザからの直接取得（CORS）を許可していないため、検索した本は公開のCORSプロキシ（cors.eu.org など）を経由して取得します。公開プロキシは混雑や停止で失敗することがあります。その場合は次のどちらかで対応できます。

- 画面に出るリンクからプレーンテキスト版を保存し、「探す」→「テキストファイルを読み込む」で読み込む
- 自分専用のプロキシを用意する: `tools/cors-proxy-worker.js` を Cloudflare Workers（無料）にデプロイし、アプリの 設定 →「独自のCORSプロキシ」に `https://<名前>.workers.dev/?url={url}` を入力（gutenberg.org 以外は中継しないようにしてあります）

同梱の60冊と辞書・検索カタログは同じサーバーから配信されるので、プロキシとは無関係に常に使えます。

## 英文法の本の取り込み

英文法コースは紙の本だけでも使えますが、自分でスキャンしたPDFを取り込むと、節のページをアプリで開いたり全文検索したりできます。

1. PC で本のパックを作ります（ページを軽い画像にして、検索用の文字を取り出します。数分かかります）
   ```
   python tools/book_pack.py "C:/Users/user/Downloads/20220530_真・英文法大全.pdf"
   ```
   `tools/.cache/book.rsvpbook`（約125MB）ができます。スキャンで抜けたページ番号も表示されます（紙の本で確認してください）
2. できたファイルを USB や Google ドライブでスマホにコピーします
3. アプリの 練習 → 英文法コース →「本を取り込む」でそのファイルを選びます

本はスマホの中（アプリの保存領域）だけに置かれ、送信もバックアップもされません。あなたが持っている本を自分で読むための機能です。パックや PDF をアプリと一緒に公開しないでください（`tools/.cache` は `.gitignore` 済みです）。必要なライブラリ: `pip install pypdf pillow`

## 和訳について

和訳には無料の機械翻訳サービス [MyMemory](https://mymemory.translated.net/) を使っています（オンライン時のみ）。無料枠は1日あたり約5,000文字で、設定でメールアドレスを登録すると約50,000文字に増えます。Chromeに内蔵の翻訳機能（Translator API）が使える端末ではそちらを優先します（2026年時点ではパソコン版Chromeのみ対応）。

## データの作り直し

同梱データ（`data/`）は `tools/build_data.py` で作っています。おすすめの本を増やしたいときは、スクリプト内の `CURATED` に Gutenberg の番号・日本語名・レベルを追加して実行します。

```
python tools/build_data.py            # 辞書・カタログ・本をすべて
python tools/build_data.py --skip-dict --skip-catalog   # 本だけ（Gutenberg・絵本・VOA）と単語デッキ
```

レベル別語彙（`data/vocab/`）の作成には wordfreq が必要です（`pip install wordfreq`）。

同梱データを更新したら、`sw.js` の `DATA_CACHE` の番号を上げると、インストール済みの端末でも新しいデータが使われます。アプリのコードを更新したときは `SHELL_CACHE` の番号を上げてください。

## クレジット

- 書籍: [Project Gutenberg](https://www.gutenberg.org/)（米国でパブリックドメインの作品。利用条件は各ファイルおよび同サイトを参照）
- 絵本: [Global Storybooks](https://globalstorybooks.net/)（[African Storybook](https://africanstorybook.org/)・[Pratham Books StoryWeaver](https://storyweaver.org.in/)、CC BY。非営利限定（CC BY-NC）の作品は除外。各話の作者・画家は `data/credits.json` とアプリの本の詳細画面に表示）
- 名作の書き直し版: [VOA Learning English](https://learningenglish.voanews.com/)「American Stories」（米国政府の著作物、パブリックドメイン）
- 英和辞書: [EJDict-hand](https://github.com/kujirahand/EJDict)（CC0）
- 単語の頻度順位: [wordfreq](https://github.com/rspeer/wordfreq)（Robyn Speer, CC BY-SA 4.0）から作成。`data/vocab/` は同ライセンス（`data/vocab/LICENSE.txt`）
- 瞬間英作文の例文: [Tatoeba](https://tatoeba.org/)（CC BY 2.0 FR。各文の番号から投稿者を確認可能。`data/COMPOSITION-LICENSE.txt`）
- シャドーイング音声: VOA Learning English（米国政府の著作物、パブリックドメイン。再生時に VOA のサーバーから取得）
- 英英辞書: [Free Dictionary API](https://freedictionaryapi.com/)（Wiktionary由来）
- 発音記号: [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)（© Carnegie Mellon University、BSDライセンス。`data/pron/LICENSE.txt`）を英和辞典式の表記に変換
